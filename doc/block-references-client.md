# 客户端笔记引用交互

## 建立引用

- 在正文输入 `[[`，选择一篇文档后，可搜索并选择其中的具体段落，也可以选择“引用整篇笔记”。
- 桌面端和移动端的斜杠菜单提供“引用段落”；笔记关系面板也提供相同入口。
- 段落引用保存目标文档 ID 和块 ID，沿用正文中的 page mention，显示目标段落当前内容。它不是复制一份摘录，也不向目标正文插入反向文本。
- 选择器打开期间，如果原段落发生变化、被删除或失去编辑权限，取消插入并提示重新选择，避免覆盖协作编辑。

## 阅读和返回来源

- 点击段落引用，打开目标笔记、定位目标块，并临时高亮三秒。
- 被引用段落旁自动显示引用来源笔记数量；点击可查看各来源笔记的引用上下文，并返回对应来源块。
- 嵌套段落同样支持来源标记；保留编辑器原有块 key 和选区行为。
- 本文内部的块引用也可反查；页级自引用不增加反向列表。
- 目标段落为空或不可用时显示明确占位提示，不静默退化成普通文档名。

## 笔记关系

- 宽屏编辑器提供可开关的“笔记关系”侧栏；窄屏保留精简的文档底部列表。
- 按来源或目标笔记分组，分别表达笔记数量和引用次数，初始展示五篇笔记，可以展开全部。
- 打开侧栏时隐藏底部重复列表；两处共用同一份关系快照。
- “查找其他提及”展示文字搜索结果，与已建立的引用分开。
- 待建立链接保留确认目标／创建笔记的操作，不自动创建笔记。
- 默认不展示索引条数、重建计数等维护信息；“刷新引用”可修复本地关系。未同步笔记可能导致结果不完整时，展示简短提示。
- 自有子页面块归为层级关系，不计作正文引用。普通链接到子页面的引用仍保留。

## 图谱

同一对文档之间保留一条连接，以箭头表示引用方向；互相引用时显示双向箭头。父子目录关系沿用独立的层级类型。

### 段落跳转修复

目标段落导航由目标编辑器统一处理：在编辑器挂载与布局完成后，先按顶层块定位（计入封面／标题列表项），再根据实际段落的渲染位置滚入可视区。嵌入式编辑器绑定自身滚动控制器；嵌套段落定位到具体子块，不停在父块开头。跨文档的块 ID 会短暂保留至目标编辑器接收，以覆盖已有标签页和 SpaceHub 只传递 view 的打开流程。连续点击会取消较早的定位请求，页面销毁后停止滚动。

新增 6 项组件测试覆盖长文档、封面偏移、嵌套块、嵌入式滚动、挂载前的导航请求、重复跳转和销毁时取消。
