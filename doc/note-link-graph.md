# 独立双链图谱

双链图谱与原有知识图谱是两个并列的产品入口。原知识图谱保留现有文档关系、实体抽取和语义关系能力；新双链图谱只探索正文中明确建立的笔记引用。

## 产品界面

- 侧边栏新增“双链图谱”，原“知识图谱”入口保留。
- 文档关系面板的图谱按钮打开以本文为中心的双链局部图谱。
- 全局图谱默认显示所有可访问笔记；没有引用的笔记以独立圆点展示、不生成连线，可通过筛选隐藏未关联笔记。
- 点选节点查看引用该笔记的来源和本文引用的目标，支持打开笔记、围绕该笔记展开 1～3 跳关系。
- 局部图谱可按入链／出链／全部方向筛选；全局和局部均支持标题搜索、仅段落引用、标题显隐。
- 箭头从引用者指向被引用者，互相引用保留两条方向相反的连线。
- 点选连线查看来源片段和目标片段，分别支持返回引用位置、定位目标段落。整篇笔记引用明确展示为页级引用。
- 桌面详情侧栏与窄屏底部详情共用同一套交互。画布支持节点拖拽、平移、缩放、适应画布；节点列表和图形语义支持辅助导航。
- 加载、读取失败重试、空结果、同步范围不完整与展示数量上限有明确反馈。

## 动画与交互

- 节点初次入场采用有阻尼的弹簧运动，轻微回弹后稳定。
- 拖拽节点时，连线随节点移动，关联节点受弹力牵引，近距离节点互相避让；松手后逐渐稳定。
- 拖节点与拖画布分开处理，拖动结束不会误触打开笔记，仍保留单击查看详情、双击打开笔记。
- 筛选更新保留仍可见节点的当前位置，平滑移动到新布局；布局更新不主动重置用户的平移和缩放。
- 动画停止后暂停帧刷新，页面销毁时清理 ticker。系统开启“减少动画”时直接展示稳定布局。

## 数据边界

节点是当前可访问的文档笔记。边来自本地 `note_link` 引用索引，按“来源笔记 → 目标笔记”聚合，但保留每条引用的来源块 ID、目标块 ID、类型和重复次数。段落引用数量与重复出现次数分别统计。

排除目录层级、自有子页面关系、AI 推断关系、无权访问／已删除的端点及自环；页内段落引用继续在编辑器中展示。图谱不扫描正文、不运行模型；仅在用户查看某条关系时读取相应块的当前内容。

每次关系查询先加载当前可访问的页面集合，接收当前工作区关系更新并刷新；权限变化后清除关系与片段缓存，丢弃旧请求返回的片段。

## 模块隔离

- 新模块：`frontend/appflowy_flutter/lib/plugins/note_graph/`
- 插件类型：`PluginType.noteGraph`
- 全局标签：`note_graph:global`
- 局部标签：`note_graph:<view-id>`
- 状态管理、图数据、力导向布局、画布和详情页均独立于 `knowledge_graph/`。
- 复用现有双链索引查询服务和段落导航服务，不修改原图谱的页面、AI 流程或布局缓存。

## 测试

- `test/unit_test/plugins/note_graph/note_graph_test.dart`：独立插件标识、数据范围、引用方向与聚合、局部筛选、布局、按需片段读取、权限变更、失败重试、工作区通知、销毁时取消。
- `test/unit_test/plugins/note_graph/note_graph_motion_test.dart`：弹簧回弹、关联牵引、无链接节点避让、减少动画、暂停恢复后的数值稳定性。
- `test/widget_test/note_graph_page_test.dart`：节点与连线详情、片段定位回调、局部／全局切换、筛选、失败重试、窄屏、预览渲染。

索引只反映本机已同步、已索引并有权访问的内容；展示上限为 400 篇笔记，可通过搜索或局部图谱缩小范围。

## 本次验证

新图谱与既有编辑器、引用导航、知识图谱的测试一起执行，共 81 项通过。另渲染桌面预览检查画布、方向箭头与片段详情；组件测试验证窄屏、鼠标点选／双击、片段跳转回调，以及文档入口不被 SpaceHub 拦截为普通页面切换。真实工作区／多设备的完整客户端验收尚未执行。
